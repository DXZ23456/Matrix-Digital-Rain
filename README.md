## 🌟 项目简介

### 中文
这是一个仿《黑客帝国》风格的交互式代码雨效果，完全使用原生HTML、CSS和JavaScript实现。该项目模拟了电影中经典的"数字矩阵雨"视觉效果，并提供了丰富的自定义选项和交互功能。

**核心特性：**
- 🎨 **多种视觉效果**：6种颜色主题、随机字符模式、故障效果模拟
- ⚙️ **高度可配置**：实时调节密度、速度、大小、尾迹长度等参数
- 🎮 **交互式控制**：鼠标悬停效果、实时状态监控、全屏模式
- 📱 **响应式设计**：完美适配桌面和移动设备
- 💾 **纯前端实现**：零依赖、单文件、离线可用

### English
This is an interactive Matrix-style digital rain effect, built entirely with vanilla HTML, CSS, and JavaScript. The project simulates the classic "digital matrix rain" visual effect from the movie, offering rich customization options and interactive features.

**Key Features:**
- 🎨 **Multiple Visual Effects**: 6 color themes, random character mode, glitch effect simulation
- ⚙️ **Highly Configurable**: Real-time adjustment of density, speed, size, trail length, and more
- 🎮 **Interactive Controls**: Mouse hover effects, real-time status monitoring, fullscreen mode
- 📱 **Responsive Design**: Perfectly adapts to both desktop and mobile devices
- 💾 **Pure Frontend**: Zero dependencies, single-file, works offline
